uiq

eslint for UI. Quality gate for UI code. 23 objective rules across motion, interaction states, accessibility, performance, and consistency.

npm MIT License 23 rules
npm install -g @sujayganorkar/uiq

Quick start

npx @sujayganorkar/uiq ./src

What it checks

Motion (5 rules)

No layout animations, duration ranges, known easing, reduced-motion, stagger intervals.

Interaction (7 rules)

Hover, focus-visible, disabled, loading, empty, error states, active route.

Accessibility (5 rules)

Keyboard nav, focus management, ARIA, touch targets, contrast.

Performance (2 rules)

Compositor-only animations, no layout thrashing.

Consistency (4 rules)

Motion tokens, single language, no generic CTAs, no card-grid heroes.
